# Temperature Converter Website

## Project Overview

This project is a Temperature Converter Website developed as part of the OASIS INFOBYTE Web Development Internship - Level 1 Task 3.

The application allows users to enter a temperature and convert it between Celsius, Fahrenheit and Kelvin.

---

## Features

- Convert Celsius to Fahrenheit
- Convert Celsius to Kelvin
- Convert Fahrenheit to Celsius
- Convert Fahrenheit to Kelvin
- Convert Kelvin to Celsius
- Convert Kelvin to Fahrenheit
- Convert temperature to all units
- Numeric input validation
- Invalid input error message
- Absolute zero validation
- Clean and responsive interface
- Mobile-friendly design
- Interactive JavaScript functionality

## Temperature Formulas

### Celsius to Fahrenheit

F = (C × 9/5) + 32

### Fahrenheit to Celsius

C = (F - 32) × 5/9

### Celsius to Kelvin

K = C + 273.15

### Kelvin to Celsius

C = K - 273.15

---

## How to Run

1. Open the project folder.

2. Open `index.html` in a web browser.

3. Enter a temperature.

4. Select the input unit.

5. Select the output unit.

6. Click "Convert Temperature".

7. The converted temperature will be displayed.

---

## Validation

The application checks:

- Empty input
- Non-numeric input
- Temperature below absolute zero

Absolute zero is:

- -273.15°C
- -459.67°F
- 0 K
