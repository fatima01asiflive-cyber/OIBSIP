# Web Development Level 1 – Landing Page

##  Project Overview

This project is a modern and responsive landing page developed as part of the Oasis Infobyte Web Development Internship – Level 1.

The landing page represents a fictional creative digital agency called **Nova**. It focuses on presenting digital services through a clean, modern, and responsive user interface.

##  Features

* Responsive navigation bar
* Modern hero section
* Call-to-action buttons
* Services section
* About section
* Contact/CTA section
* Footer
* Responsive design for desktop, tablet, and mobile devices
* Smooth scrolling navigation
* Hover effects and modern card-based UI

##  Technologies Used

* HTML5
* CSS3
* CSS Grid
* CSS Flexbox
* Media Queries
* Responsive Web Design

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

You can also use **Live Server** in Visual Studio Code for a better development experience.
