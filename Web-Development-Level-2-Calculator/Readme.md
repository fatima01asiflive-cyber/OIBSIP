# OASIS INFOBYTE - Level 2 Task 1 Calculator

A fully functional and responsive calculator built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Display screen
- Number buttons from 0 to 9
- Decimal point
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Equals button
- Clear button
- Delete/Backspace button
- Division by zero validation
- Operator chaining
- CSS Grid layout
- JavaScript event listeners
- No inline onclick events
- No eval() function
- Responsive design
- Keyboard support

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the calculator.
