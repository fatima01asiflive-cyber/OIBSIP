# To-Do Web App

A responsive and interactive To-Do Web App created using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Add new tasks
- Display pending tasks
- Complete tasks
- Move completed tasks to completed list
- Edit tasks
- Delete tasks
- Pending task count
- Completed task count
- Total task count
- Task timestamps
- Empty-state messages
- LocalStorage persistence
- Responsive design
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

## How to Run

1. Open the project folder.
2. Open `index.html` in a web browser.
3. Enter a task in the input field.
4. Click "Add Task".
5. Use the checkbox to complete a task.
6. Use the edit button to change a task.
7. Use the delete button to remove a task.

## LocalStorage

Tasks are automatically saved in the browser's LocalStorage.

This means tasks remain available even after refreshing the page.
